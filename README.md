# ELORIA — Conseil, stratégie & analyse

Site vitrine statique et portail d'applications d'ELORIA.

## Structure
- `index.html` : présentation du cabinet, expertises, offres, applications et contact.
- `style.css` : identité visuelle responsive et blocs différenciés par couleur.
- `script.js` : navigation mobile et année dynamique.

## Applications présentées
1. **Tableau** — application d'analyse territoriale.
2. **Distrib** — application de distribution.
3. **RPG Polygone** — application autour des données et polygones RPG.

Les noms « Tableau » et « Distrib » reprennent la lecture des annotations manuscrites et pourront être confirmés ou corrigés.

## Publication GitHub Pages
1. Ouvrir **Settings** dans le dépôt.
2. Aller dans **Pages**.
3. Dans **Build and deployment**, choisir **Deploy from a branch**.
4. Choisir la branche **main** et le dossier **/(root)**, puis enregistrer.
5. Attendre la fin du déploiement GitHub Pages.
